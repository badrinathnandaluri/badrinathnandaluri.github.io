clipper

A personal publishing tool for the bootstraped_07 channel.

What it does. clipper turns highlights from public gaming livestreams into short vertical videos and publishes them to the channel owner's own YouTube channel (as Shorts) and Instagram account (as Reels), using the official YouTube Data API and Instagram API.

Who uses it. Only the owner of the bootstraped_07 accounts. It is not a public service, it has no sign-up, and it never accesses anyone else's account or data.
